Open roles Technical detail

01The work

What you would work on.

A clean-sheet architecture already in production, and a second generation with specifications frozen. There is no legacy codebase to maintain.

Silicon

Compute unit and composition

Scalar control plane, our DSP data plane, domain-specific instructions, and the composition model that scales one verified unit into a catalogue. Microarchitecture, memory subsystems and power.

Firmware

Runtime and signal processing

Deterministic runtime, over-the-air update, and the signal-processing firmware that improves deployed systems after installation. Real-time systems and hardware-software co-design.

Tools

Compiler and toolchain

Compiler and toolchain work on a standard RISC-V base, extended into the signal domains. This determines how usable the architecture is outside the team that designed it.

Systems

Integration and certification

5G physical layer, stack integration, interoperability and certification, taking the architecture to a level an operator will accept.

02How we work

How we work.

Verification

First-time-right

Every generation the CTO has architected reached silicon without a re-spin. This is a function of how designs are reviewed before commit.

Ownership

Blocks owned end to end

Engineers take blocks from specification through bring-up rather than working on isolated segments.

Roadmap

Published dates

Product and technology dates are published openly, and reviewed as each generation progresses.

Proximity

Silicon and customers in one team

Design and deployment teams work together, so requirements come directly from the systems being built.
